Key Takeaways & Architectural Summary

Summary of how this feature strengthens academic integrity and elevates the user interface:

⚙️ How It Works Under The Hood

  • Single Ingestion: The HOD configures one syllabus and blueprint once (70 Marks, 5 Units, Bloom's percentages).
  • Concept Partitioning: The engine extracts learning topics. When Set A uses a topic (e.g., Stacks), that topic is blacklisted for Sets B & C, ensuring 0% topical overlap.
  • Equi-Difficulty Parity: All 3 sets have mathematically identical difficulty and cognitive depth so no student receives an unfairly hard or easy paper.
  • Sealed Batch Archive: All 3 sets are saved under one Batch ID (e.g. BATCH-2026-CS301).

🖥️ How The UI Changes

  • QP Generator Screen (/hod/generate): Adds a clean "Generation Mode" selector: Single Paper vs. ⭐ 3 Parallel Sets (A, B, C). Everything else stays identical.
  • QP Archives Screen (/hod/papers): Groups papers into a Unified Batch Card with clickable tabs [Set A], [Set B], [Set C] instead of cluttered separate rows.
  • Exam Day "Random Draw": Adds an authorized button 🎲 Random Draw Active Set so the Controller of Examinations picks the live set on exam morning.
